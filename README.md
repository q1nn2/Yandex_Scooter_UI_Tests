# Яндекс Самокат — UI-автотесты

Набор автоматизированных UI-тестов для сервиса «Яндекс.Самокат».

Проект покрывает ключевые пользовательские сценарии веб-приложения: работу FAQ, оформление заказа и навигацию по основным элементам интерфейса. Тесты построены по Page Object Model, запускаются в Firefox через Selenium WebDriver, поддерживают параметризацию в Pytest и формируют Allure-результаты. Для автоматической проверки настроен запуск в GitHub Actions.

## Покрытие

- 8 проверок блока «Вопросы о важном»;
- полный позитивный сценарий оформления заказа;
- два набора тестовых данных для заказа;
- две точки входа в оформление заказа;
- проверка перехода по логотипу «Самокат»;
- проверка открытия Дзена в новом окне по логотипу Яндекса;
- проверка отображения сообщения об успешном создании заказа.

## Технологии

`Python` · `Pytest` · `Selenium WebDriver` · `Firefox` · `Page Object Model` · `Allure` · `GitHub Actions`

## Архитектура

Проект разделён на независимые слои:

- `pages/` — Page Object-классы и действия со страницами;
- `locators/` — локаторы элементов интерфейса;
- `tests/` — тестовые сценарии, сгруппированные по функциональности;
- `data.py` — тестовые данные и URL;
- `conftest.py` — фикстура WebDriver;
- `allure_results/` — результаты выполнения тестов;

## Тестовые сценарии

### FAQ

Для каждого вопроса выполняется отдельная проверка: тест открывает нужный пункт аккордеона и сравнивает фактический текст ответа с ожидаемым. Набор проверок запускается через параметризацию Pytest.

### Оформление заказа

Проверяется полный пользовательский путь: открытие формы заказа, заполнение данных, выбор станции метро, даты и срока аренды, выбор цвета, добавление комментария, подтверждение заказа и отображение сообщения об успешном создании заказа.

Сценарии выполняются через обе доступные точки входа — верхнюю и нижнюю кнопки «Заказать» — с разными наборами данных.

### Навигация

Проверяется переход на главную страницу по логотипу «Самокат» и открытие Дзена в новом окне после клика по логотипу Яндекса.

## Установка

```powershell
python -m pip install -r requirements.txt
```

Для локального запуска требуется Mozilla Firefox.

## Запуск тестов

```powershell
pytest
```

## Allure

Запуск тестов с сохранением результатов:

```powershell
pytest --alluredir=allure_results
```

Открытие отчёта:

```powershell
allure serve allure_results
```

## CI

Тесты автоматически запускаются в GitHub Actions при изменениях в ветке `main`, при обновлении Pull Request в `main` и вручную через `workflow_dispatch`. Результаты Allure сохраняются как артефакт запуска.
