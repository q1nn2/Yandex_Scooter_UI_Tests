# Yandex Scooter UI Test Automation

Проект автоматизации UI-тестирования учебного сервиса «Яндекс.Самокат».

В проекте реализована тестовая архитектура на **Page Object Model**, параметризованные сценарии на **Pytest**, запуск браузера через **Selenium WebDriver**, формирование **Allure-отчётов** и автоматический прогон тестов в **GitHub Actions**.

## Что реализовано

- проверка 8 сценариев блока «Вопросы о важном»;
- позитивный end-to-end сценарий оформления заказа;
- два набора тестовых данных для заказа;
- проверка обеих точек входа в оформление заказа;
- проверка перехода по логотипу «Самокат»;
- проверка открытия Дзена в новом окне после клика по логотипу Яндекса;
- явные ожидания для работы с динамическими элементами;
- отдельный слой локаторов;
- Page Object Model с базовым классом страницы;
- Allure steps и отчётность;
- автоматический запуск тестов в Firefox через GitHub Actions.

## Стек

`Python` · `Pytest` · `Selenium` · `Firefox` · `Page Object Model` · `Allure` · `GitHub Actions`

## Тестовые сценарии

### FAQ

Каждый вопрос проверяется отдельно через параметризацию. Тест открывает нужный пункт и сравнивает фактический текст ответа с ожидаемым.

### Оформление заказа

Проверяется полный пользовательский сценарий: переход к форме, заполнение данных, выбор параметров аренды, подтверждение заказа и появление сообщения об успешном оформлении.

Сценарий запускается для двух точек входа: верхней и нижней кнопки «Заказать».

### Навигация

Проверяется возврат на главную страницу по логотипу «Самокат» и открытие Дзена в новом окне по логотипу Яндекса.

## Установка

```powershell
python -m pip install -r requirements.txt
```

Для локального запуска должен быть установлен Mozilla Firefox.

## Запуск тестов

```powershell
pytest
```

## Запуск с Allure

```powershell
pytest --alluredir=allure_results
allure serve allure_results
```

## CI

При обновлении ветки `develop` и Pull Request в `main` тесты автоматически запускаются в GitHub Actions на Firefox.

Последний проверочный прогон: **12/12 тестов успешно пройдены**.
